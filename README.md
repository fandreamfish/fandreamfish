## 🐠 fishbowl —— 现在在做的事

一个你**养出来**、而不是**配置出来**的 AI。

> 记忆、情绪、人格都不是设定项——它们从对话与行动中生长出来。

- **人格不预设**：没有“人格插件”，人格是行为长期积累出来的轨迹
- **情绪是真的**：情绪会改变决策（6 个偏置旋钮），而不只是改变措辞
- **有自己在意的事**：自己的议程、未兑现的承诺、没翻篇的事
- **会反思**：反思必须能得出“我错了”，而不是总能证明自己有理
- **一个个体一个缸**：记忆、气质、情绪、配置互相隔离；一条鱼一个房间，终身唯一
- **她活着**：清醒节律、主动联系、自处、QQ 通道、DSH 常驻
- **有边界**：做事前可以向你申请；没等同意就做了会被记下来（许可 + 审计）

**最近做完的**

- 每条鱼一份完整 `config.json`，设置页改完即存；读写同一份文件，缺键写入时自愈
- 许可：申请 → 同意 → 签发（范围/次数/期限）→ 消费；未获许可的动作记 `breach`
- 家目录：`creatures/<id>/home/`，日记、小纸条、她自己的东西都在这里；其它目录只读
- 导出/导入：打包全部鱼，幂等导入，自动安置进「大肥鱼的屋子」
- 记忆：每轮双总结 → 合并 → 召回 → 预算注入；空闲也会整理
- B 站：只读浏览、热评/弹幕、评论与回复、风控冷却；登录只落本机
